
# Random Ambient Audio

Play short ambient audio clips, like wind howling or wood creaking, at a position in world, picking the clip with weighted randomness and random delay, however every player will hear the same audio at the same time.

# Installing

Then head to my [VCC Listing](https://jansharp.github.io/vrc/vcclisting.xhtml) and follow the instructions there.

# Contents

2 example prefabs, 1 for window howling and 1 for wood creaking. With royalty free (and custom cut and edited) audio files, ready for use.

3 wind loop sounds, also royalty free a little edited. Interior, exterior and exterior-sheltered. Use with [Music Control](https://github.com/JanSharp/VRCMusicControl) for example. (When using Music Control for this, use Global Time Since World Start (synced or not) for the 2 exterior Music Descriptors for clean fade transitions).

A few scripts, of course, also serving as a small example for a part of the [lockstep networking](https://github.com/JanSharp/VRCLockstep) API. Specifically a random number generator - part of the game state - and lockstep delayed events. The fact that this system plays random audio at random times, while every player hears the same thing, is heavily reliant on the guarantees and framework lockstep provides, the scripts are tiny.

# Contributing

This project uses [custom git filters](.gitattributes) to reduce the amount of noise generated by Udon and UdonSharp. These filters are not required in order to contribute, though without them all UdonSharp asset files will show as modified and those "changes" should not be committed.
